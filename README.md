# TalentScan 2036

**Prototype, work in progress.** Smartphone countermovement jump (CMJ) and physics-informed vGRF estimation demo.

## Try it

- Live site: https://praveenmaths89.github.io/talentscan-2036/
- Or open `index.html` / `talentscan_pinn_standalone.html` in a browser (HTTPS needed for live DeviceMotion on phones).

## What it does

- Capture or simulate a chest-held smartphone IMU jump
- Compare PINN neural + impulse-anchored vGRF vs raw IMU
- Export CSV / trial JSON for research pairing with force plates

Google Sign-In is disabled in this public prototype (OAuth client ID stripped). Location defaults are generic placeholders, not real athlete records.

## Note

This is a research prototype. Do not use it for medical decisions or athlete selection without validation.
